#  Application de Suivi et Enregistrement de Colis



Une application web complète conçue pour une compagnie de transport, permettant la gestion efficace des colis, le suivi en temps réel pour les clients et l'enregistrement simplifié pour les employés.

---

##  Fonctionnalités

L'application comprend cinq sections principales conçues pour répondre aux besoins des clients et des employés :

*   **Tableau de Bord :** Vue d'ensemble des statistiques (colis en transit, livrés, en attente) et des activités récentes.
*   **Enregistrement des Colis :** Formulaire complet pour les employés afin de créer un nouvel envoi avec génération automatique d'un numéro de suivi.
*   **Suivi des Colis :** Interface de recherche permettant aux clients de suivre l'état de leur envois en temps réel via une timeline visuelle.
*   **Historique des Envois :** Liste paginée et filtrable de tous les colis enregistrés dans le système.
*   **Support Client :** Formulaire de contact intégré pour permettre aux utilisateurs de soumettre des demandes d'assistance.

*   **Backend :** PHP , Framework Laravel 
*   **Frontend :** HTML5, CSS3, Bootstrap 5
*   **Base de Données :** MySQL

*   **Versionning :** Git & GitHub
* 


##  Rôles Utilisateurs

L'application gère deux types d'utilisateurs avec des permissions différentes :

*   **Client :** Peut se connecter, suivre ses colis, voir son historique et contacter le support.
*   **Employé :** Peut se connecter, enregistrer de nouveaux colis, mettre à jour les statuts et gérer les demandes de support.
